# Costruire osservabili giuridici · Il diritto allo studio

Sito che accompagna la tesi di laurea di Antonella Ninfadoro (Università degli Studi del Sannio, A.A. 2025/2026, relatore prof. Nicola Lettieri), capitolo IV.

Applica il framework per la costruzione computazionale degli osservabili giuridici al diritto allo studio degli studenti con malattia oncologica o con disabilità, a partire dall'art. 16 della legge 104/1992.

- `index.html` · il framework
- `testo/` · primo prototipo, la disposizione
- `relazioni/` · secondo prototipo, la rete delle norme
- `effetti/` · terzo prototipo, il percorso dello studente (simulazione)

Sito statico (HTML, CSS, JavaScript), pubblicato con GitHub Pages. Le decisioni sono in `DECISIONI.md`.

La prima applicazione del framework, sull'art. 33, è in un repository separato: https://antonellaninfadoro.github.io/Nuovi-osservabili-giuridici-/
